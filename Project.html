Internal Processing Walkthrough

What Actually Happens Inside AnvayaRx

Every request crosses three internal hops before it ever reaches a payor solution — each with one clear job. Watch it happen, hop by hop.

Agent 1 — Inbound

Standardize

Authenticates the caller, validates the incoming XML or JSON, and converts it into AnvayaRx's one canonical format.

AnvayaRx App — Not An Agent

Audit & Log

Writes an immutable, Case-linked audit entry for every exchange, then hands the standardized request to Agent 2.

Agent 2 — Outbound

Convert & Deliver

Looks up the payor's routing rule, converts to that solution's own schema — XML or JSON — and delivers to the right endpoint.
