Internal Processing Walkthrough

What Actually Happens Inside AnvayaRx

Every payor solution is wired up and waiting. Pick one, and watch the request cross all three internal hops and get routed to exactly that endpoint — while the others stay untouched.

Agent 1 — Inbound

Standardize

Authenticates the caller, validates the incoming XML or JSON, and converts it into AnvayaRx's one canonical format.

AnvayaRx App — Not An Agent

Audit and Log

Writes an immutable, Case-linked audit entry for every exchange, then hands the standardized request to Agent 2.

Agent 2 — Outbound

Route, Convert, Deliver

Matches the payor group to its routing rule, converts to that solution's own schema, and delivers to the right endpoint.
